# v5.1.3-dojobay.10

The paired-explorer policy lands whole: on-chain lookups bind to the
Dojo's own explorer, only an onion explorer binds as paired, and every
third-party load carries the consent advisory. A deep hardening sweep
of PSBT and import surfaces rides along, plus Tor 0.4.9.14 and
BouncyCastle 1.86.

## Fixed since v5.1.3-dojobay.9

### Paired-explorer policy (#342 via #512, #517, #518)

- Explorer lookups bind to the paired Dojo (#512): the Dojo-declared
  explorer serves every built-in on-chain surface by default, the
  shortened onion shows its tail so it can be verified (#513), and a
  standing check says who runs the paired Dojo.
- Only an onion explorer binds as the paired explorer (#518, SR-23): a
  pairing payload — community-list Dojo included — that publishes a
  clearnet URL leaves the lookup unbound. The authority's host decides,
  so userinfo (`x.onion@evil.example`) and path
  (`https://evil.example/onion.onion`) tricks cannot fake an onion.
  A clearnet Custom URL carries the same third-party advisory as the
  mempool choice; the final page URL decides, not the saved template.
- The block explorer re-probes when the Tor SOCKS session changes
  (#517): a probe result from a dead Tor session no longer stands.
- Explorer loads explain themselves when Tor stops first (#502).

### PSBT and import security (#469, #477, #471)

- Native SegWit PSBT inputs no longer trust Dojo amounts (#469 via
  #478): the prev-tx txid, index, and amount are verified per input,
  failing closed on mismatch or fetch failure.
- Compose input-script agreement and PSBT UTXO consistency (#477 via
  #493, #498); sweep sign+broadcast is gated on UTXO chain
  verification.
- Untrusted PSBT, transaction, label, and paste reads are bounded
  (#501); previous-transaction reads are bounded and fail closed on
  malformed script hex (#503 via #507); the unused getTxHex timeout is
  gone and prev-tx refusals stay generic (#508).
- Backup and transaction imports enforce real size limits (#471 via
  #479).
- PSBT globals end on the BIP-174 separator (#462 via #466); dust
  outputs are rejected when composing (#463 via #467); Broadcast says
  PSBT (#464 via #474).

### Sync round honesty (#475, #489, #487, #499, #491)

- An imported backup lands its tx history on the first sync round
  (#475 via #486) instead of duplicating collections (#497); a second
  import merges instead of doubling.
- A failed sync round no longer re-arms on its own writes, and a
  trailing re-run is gated on the round's start signature (#489 via
  #490); off-network collections are skipped in a round (#487 via
  #509); fetchBalance reports partial collection failures (#499 via
  #506); collection edit Save persists and closes on the first tap
  (#495). The deterministically-Indeterminate round (#491) closed
  with this family.

### Privacy and pairing

- The Dojo token authenticator is origin-gated (#468 via #476): a
  third-party 401 can no longer disclose the Dojo access token; one
  re-auth is shared across concurrent 401s (#470 via #494).
- The add-key PubKeyModel stays off Intent extras (#484 via #492), the
  SegWit import XPUB too (#465 via #482).
- Dojo pairing credentials and the pairing QR are kept always secure
  (#516); the scanner stays secure while scanning; the pairing
  suggestion is dropped from the analysis advisory.
- The Dojobay area follows the Disable Screenshots setting (#511 via
  #514).
- Restore from a current-format backup offers to set a PIN (#420 via
  #456, #496), keeps the offer above the import button (#460 via
  #461), and the set-PIN flow closes its pad records by name so the
  remove toggle works (#433/#440 via #439, #441).

### Pairing and label-import UX

- Pairing payload failures are told apart (#399 via #448); passwords
  typed without separators are accepted (#431 via #443); the camera
  permission is asked on the scan page, not the doors (#432 via #445);
  the success snackbar gets its object and a sentence break (#436 via
  #442).
- Sparrow BBQr label exports import (#70 via #453): series integrity
  and inflate are hardened (#454), part count shows while scanning,
  garbled frames are skipped, missing indexes log in QRPerf, and scans
  pause under the BBQr conflict dialog (#457).
- UR part outcomes are counted and QR analysis is faster (#71 via
  #451); QRPerf counters cover animated-UR label scans (#447).
- Off-network collections grey out (#429 via #430, #434, #435, #437,
  #438) with a two-line badge the item animators cannot whiten.
- BIP-329 copy names Ashigaru Desktop alongside Sparrow (#458 via
  #459).

## Worth a specific check

1. Pair a Dojo whose payload publishes a clearnet explorer URL: the
   lookup stays unbound and offers mempool.space or Analyze
   externally; nothing loads silently (#518 / SR-23).
2. Pair a Dojo with an onion explorer: lookups bind, the shortened
   onion shows its tail, and no advisory interrupts (#512, #513).
3. Sweep a UTXO with a tampered amount: sign+broadcast refuses (#477
   via #498).
4. Import a backup: history lands on the first sync round, no
   duplicate collection (#475 via #486, #497).
5. Pair, then let Tor stop: the explorer probe re-runs on the next
   SOCKS session; a clearnet Custom URL load asks first (#517, #518).
6. Restore a keyless install: the set-PIN offer appears above Import
   and the PIN toggle turns off on the first try (#420 via #456, #433
   via #439/#441).
7. Scan a Sparrow BBQr label export: parts count up, garbled frames
   skip, and the import lands (#70 via #453/#454).
