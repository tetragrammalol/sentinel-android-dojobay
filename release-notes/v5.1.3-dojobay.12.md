# v5.1.3-dojobay.12

6.0.0 Release Candidate 1, import hotfix. The Import screen
gains a SCAN button, so a Sentinel backup or an Ashigaru
pairing can arrive by camera. Import via QR is an essential
path for users coming from Ashigaru - its default pairing
export is a QR - and RC1 shipped with no camera path on that
screen. 1 PR since v5.1.3-dojobay.11; 1 issue closed.

## Fixed since v5.1.3-dojobay.11

### Import gains a camera path (#544)

- Settings > Import (`ImportBackUpActivity`) gains a SCAN
  button beside CHOOSE FILE and PASTE (#544 via #545). A scan
  entry point existed only through the + Add sheet, which
  users do not look for when importing. Tapping SCAN is the
  only time this screen asks for the camera.
- On grant, a single-shot sheet reuses the existing
  Hummingbird scanner (`ScanPubKeyFragment`) with that
  scanner's paste button hidden. Declining the ask shows a
  snackbar and leaves Choose file, Scan, and Paste usable. A
  cancelled or denied permission result does not open the
  scanner.
- The first admitted decode closes the sheet, clears the
  preview, applies the same `ImportLimits.BACKUP_MAX_BYTES`
  cap as PASTE - an over-cap scan shows the PASTE size
  message - and calls the same `validatePayload` path: an
  accepted scan is the exact string PASTE hands to
  `validatePayload`. A blank decode is ignored and the
  camera stays up.
- A QR that `validatePayload` would not arm - for example a
  URL, an empty object, or a pairing object without payload -
  closes the sheet with one message, "That QR isn't a Sentinel
  backup or Ashigaru pairing". No toast spam, no frozen
  preview (#232 policy).
- The scan sheet blocks screenshots the whole time it is
  open, whatever Disable Screenshots says, matching the Dojo
  pairing camera: an Ashigaru pairing QR can carry encrypted
  Dojo credentials. Closing the sheet leaves the Import
  screen on the setting.
- The decoded text is not logged. Decryption, the password
  field, the Ashigaru version check, the network guard, and
  the Dojo pairing leg are unchanged.
- Animated multi-frame backups (BBQr / UR) and full Sentinel
  backup files that do not fit in one QR stay out of scope;
  the pairing QR is the supported camera import.

## Worth a specific check

1. Ashigaru: show the pairing QR, Sentinel Settings >
   Import > SCAN, scan, type the pairing words, Import:
   collections (and Dojo if included) arrive exactly as via
   PASTE.
2. Deny the camera ask: a snackbar, and Choose file, Scan,
   and Paste stay usable. Granting later works.
3. Scan a random QR (for example a URL): one neutral
   message, no loop, no toast spam.
4. Screenshots stay blocked on the scan sheet whether
   Disable Screenshots is on or off. Closing the sheet
   returns the Import screen to the setting.
5. Choose file, Scan, and Paste fit at 320dp without
   overlapping or ellipsizing.
