# v5.1.3-dojobay.8

Whirlpool labelling, the auto-labels toggle, the Ashigaru icon restyle, and
the follow-up red-team fixes since v5.1.3-dojobay.7. A number of earlier UX
and export fixes that landed on master in the same window ride along.

## Fixed since v5.1.3-dojobay.7

- Per-tab Tx0 display (#343 via #380, #381): a stored "Whirlpool Tx0" label
  now reads as Premix / Bad Bank / Tx0 from the row's own account; Tx0 is
  also recognised without a Bad Bank output when premix outputs sit in one
  pool window.
- First-mix and Bad Bank Tx0 detection (#197 via #382, #383, #386, #387):
  mixes are recognised from own inputs/outputs and observed amounts; Tx0
  funded from Bad Bank is labelled; full history paging feeds the detector
  when auto-labels are on (caps: 10,000 rows / 200 pages).
- Auto-labels toggle polish (#388) and red-team hardening (#392, #393):
  `/txs` paging runs only with the toggle on; paging is incremental with
  caps; with the toggle off the confirmed stored tail is kept and
  unconfirmed misses are dropped; manual labels always persist and are
  never overwritten by auto-labels; a one-time migration demotes
  hand-edited `auto:` rows; a blank BIP-329 tx/output import is stored as
  a manual clear (export still skips blanks).
- Ashigaru collection icon restyled onto the wallet palette (#345 via #389).
- Import / sweep polish (#377, #378, #379): toast when no document picker,
  sweep Next label clear of the spinner, KDF overlay while an imported PIN
  is saved.
- Release builds pin Temurin JDK 21.0.8+9 so the staging APK stays reproducible (#390).
